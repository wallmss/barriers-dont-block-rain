# Barriers Don't Block Rain (BDBR)

Um mod client-side para Minecraft **1.8.9 (Forge)** que faz **chuva e neve atravessarem blocos de barreira** — perfeito para arenas de PotPvP / Boxing que usam teto de barreira.

## ✨ Features

- ☂ Chuva atravessa barreira
- ❄ Neve atravessa barreira
- ⚡ Trovoada com relâmpagos visíveis
- ☀ Forçar clima limpo
- 🎛 Toggle on/off da barreira

## 🎮 Comandos

| Comando | Descrição |
|---|---|
| `/bdbr on` / `off` | Liga/desliga a passagem pela barreira |
| `/bdbr rain` | Força chuva client-side |
| `/bdbr snow` | Força neve client-side |
| `/bdbr thunder` | Força trovoada client-side |
| `/bdbr clear` | Força clima limpo |
| `/bdbr vanilla` | Volta ao clima do servidor |
| `/bdbr status` | Mostra o status atual |
| `/credito` | Créditos |

## 📦 Instalação

1. Instale o **Minecraft Forge 1.8.9**.
2. Coloque o `.jar` na pasta `mods/`.
3. Pronto.
